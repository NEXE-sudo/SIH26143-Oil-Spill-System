# Drift runs cache

Precomputed PyGNOME hindcast/forecast output, read by
`app/services/drift.py`. Generated by `scripts/run_pygnome_drift.py`
(run separately, in a conda environment with PyGNOME installed — never
imported by the FastAPI app itself).

File naming: `{spill_id}_hindcast.json`, `{spill_id}_forecast.json`.

These are small (a few hundred KB at most) and should be committed —
they're what makes the demo work offline without PyGNOME installed on the
presentation machine. Any `spill_id` without a cached file here falls back
to the synthetic drift model in `app/services/drift.py`.
